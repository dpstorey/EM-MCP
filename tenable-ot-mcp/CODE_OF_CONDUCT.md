# Code of Conduct

This project follows the
[Contributor Covenant v2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).

In short: be respectful, give the benefit of the doubt, focus on the
work. Harassment, insults, or discriminatory comments aren't tolerated
in any project space (issues, merge requests, commits, chat, email).

To report an unacceptable interaction, contact the maintainer through GitHub
([@dpstorey](https://github.com/dpstorey)) or, to keep it private, use
[GitHub private reporting](https://github.com/dpstorey/EM-MCP/security/advisories/new).

Reports are confidential. We'll investigate and take action
appropriate to the severity, up to and including removing offenders
from the project.
